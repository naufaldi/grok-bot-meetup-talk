# Grok Bot Meetup deck

Open Slide deck for the Grok Bot meetup talk. 22 pages, light theme, official SpaceXAI wordmark and Grok Bot mark, animated eyes.

Source: `slides/grok-bot-meetup/index.tsx`. Design notes: `themes/grok-bot-brand.md`.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static bundle in dist/
npm run preview
```

Press `F` (or Present) to play. The eye blinks, page enters, and diagram draws only run in play mode. The editor's Inspect mode freezes motion on purpose.

## Story

1 Title, 2 Who I am, 3 Agenda, 4 SpaceXAI, 5 Grok, 6 Grok Bot, 7 Teammates, 8 Maturity curve, 9 Problem, 10 Solution, 11 How it works, 12 to 16 Use cases (Inbox Triage, Motion Studio, Community Ops, English practice, OSINT Scout), 17 Student example, 18 Demo, 19 Getting started (QR), 20 Praktek, 21 Q&A, 22 Thank you.

Speaker notes are in the `notes` export and show in the presenter view.
